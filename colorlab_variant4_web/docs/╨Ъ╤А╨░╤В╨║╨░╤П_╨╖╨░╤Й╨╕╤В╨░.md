# Краткая защита проекта

- Вариант 4: **RGB ↔ HSV ↔ LAB**.
- HSV считается напрямую из RGB.
- LAB считается через XYZ: `RGB ↔ XYZ ↔ LAB`.
- Готовых RGB↔XYZ-матриц в проекте нет: матрица строится по sRGB primaries и текущей точке белого.
- При `D65/D50/E` вызывается `ColorConverter.setIlluminant()`, который строит новый контекст и новые матрицы.
- Обращение 3×3-матрицы реализовано вручную в `matrix.js`.
- `Clipping` ограничивает каждый линейный RGB-канал отдельно. `Scaling` совместно сжимает диапазон.
- Динамический градиент каждого слайдера рассчитывается при текущих значениях остальных компонент.
- Архитектура: `model/` — математика, `view/` — DOM, `controller/` — связь между ними.
- `npm test` запускает 28 микро-тестов, включая `RGB(255,0,0)` → HSV и LAB.

## Запуск без Node.js

```bash
python -m http.server 8000
```

Приложение: `http://localhost:8000/`

Автотесты: `http://localhost:8000/tests/`

На защите удобно открыть страницу тестов и показать итог `28 / 28`, затем вернуться в приложение по кнопке «Вернуться к приложению».
