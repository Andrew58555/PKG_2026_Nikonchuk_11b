## Тест №01: Линейное контрастирование малоконтрастного изображения
**Файл:** `low_contrast.png` · **Метод:** linear · **Статус:** ПРОЙДЕН
**Цель:** Проверить растяжение узкого диапазона яркости и сохранение размера изображения.
**Параметры:** `{'lowPercent': 2, 'highPercent': 98}`
### Ручной расчёт
- Iнов = round(255 × (I − a) / (b − a))
- Iнов = round(255 × (128 − 115) / (143 − 115)) = round(118,39) = 118
**Ожидалось:** Контрольное значение должно совпасть с формулой; крайние диапазоны ограничиваются 0 и 255.
**Результат:** Пиксель (320,210): 128 → 118. Яркость: 112–143 → 0–255; σ: 7,774 → 70,557.
**Примечание:** Контраст заметно усилился: распределение яркости растянуто на весь диапазон. Контрольная точка рассчитана по процентильным границам.

## Тест №02: Локальное среднее — документ с тенью
**Файл:** `shadow_document.png` · **Метод:** local-mean · **Статус:** ПРОЙДЕН
**Цель:** Проверить локальный порог при неоднородной яркости фона; сравнить три локальных метода.
**Параметры:** `{'windowSize': 21, 'borderMode': 'reflect'}`
### Ручной расчёт
- μ = ΣI / N = 52 556 / 441 = 119,1746
- T = μ. 40 ≤ 119,1746 → выход 0 (чёрный)
**Ожидалось:** Контрольный тёмный пиксель должен перейти в чёрный класс; результат бинарный.
**Результат:** Пиксель (168,100): 40 → 0. Чёрных пикселей 67,200%; белых 32,800%.
**Примечание:** Тень и граница листа попадают в тёмный класс, что повышает долю чёрных пикселей. Это показывает ограничение локального среднего для теневых участков.

## Тест №03: Niblack — неравномерное освещение
**Файл:** `uneven_lighting.png` · **Метод:** niblack · **Статус:** ПРОЙДЕН
**Цель:** Проверить реакцию Niblack на локальное среднее и разброс яркости.
**Параметры:** `{'windowSize': 21, 'k': -0.2, 'borderMode': 'reflect'}`
### Ручной расчёт
- μ = 31 065 / 441 = 70,4422
- σ = √(2 316 827 / 441 − 70,4422²) = 17,0727
- T = μ + kσ = 70,4422 − 0,20 × 17,0727 = 67,0276
- 55 ≤ 67,0276 → 0 (чёрный)
**Ожидалось:** Тёмный пиксель текста должен стать чёрным; выход содержит только 0 и 255.
**Результат:** Пиксель (100,125): 55 → 0. Чёрных пикселей 20,102%; белых 79,898%.
**Примечание:** Локальный разброс учитывается через σ; порог ниже среднего на 0,2σ. Контрольная точка текста попала в чёрный класс.

## Тест №04: Sauvola — градиентный фон
**Файл:** `gradient.png` · **Метод:** sauvola · **Статус:** ЧАСТИЧНО
**Цель:** Проверить адаптивный порог при плавном изменении яркости по изображению.
**Параметры:** `{'windowSize': 21, 'k': 0.05, 'R': 128, 'borderMode': 'reflect'}`
### Ручной расчёт
- μ = 26 412 / 441 = 59,8912
- σ = √(1 597 038 / 441 − 59,8912²) = 5,8695
- T = 59,8912 × [1 + 0,05 × (5,8695 / 128 − 1)] ≈ 57,0339
- 57 > 57,0339? Нет: 57 < 57,0339 → выход 0 (чёрный)
**Ожидалось:** Небольшой объект должен быть отделён от плавно меняющегося фона.
**Результат:** Пиксель (100,125): 57 → 0. Белых пикселей 99,613%; чёрных 0,3873%.
**Примечание:** Метод рассчитан корректно, но почти всё изображение перешло в белый класс. Выбранные k, R и размер окна не обеспечили отделение объекта от градиентного фона.

## Тест №05: Оцу — шумное изображение
**Файл:** `noise.png` · **Метод:** otsu · **Статус:** ПРОЙДЕН
**Цель:** Проверить устойчивость глобального порога Оцу на шумном изображении.
**Параметры:** `{}`
### Ручной расчёт
- Порог t = 83; классы: 0…83 и 84…255
- Контрольный пиксель I = 160: 160 > 83 → 255 (белый)
- σ²B = w₀ × w₁ × (μ₀ − μ₁)² ≈ 5,3559 × 10¹³
**Ожидалось:** Низкие и высокие яркости разделены автоматическим порогом; выход бинарный.
**Результат:** Оцу: t=83. Контрольный пиксель 160 → 255. Чёрных 3,027%; белых 96,973%.
**Примечание:** Оцу выбрал порог по распределению классов. Шумовые выбросы не удаляются автоматически: алгоритм бинаризует, а не фильтрует шум.

- Порог t = 102
- Тёмная точка I = 35: 35 ≤ 102 → 0

## Тест №08: CLAHE — тёмная сцена
**Файл:** `night_sign.png` · **Метод:** clahe · **Статус:** ПРОЙДЕН
**Цель:** Проверить локальное выравнивание контраста CLAHE на тёмной сцене.
**Параметры:** `{'tiles': 8, 'clipLimit': 2}`
### Ручной расчёт
- L = floor(2 × 4 240 / 256) = 33 (лимит отсечения для корзины)
- В соседних тайлах: LUT верхний = round(255 × 418 / 4 240) = 25; нижний = round(255 × 496 / 4 240) = 30
- Интерполяция: 25 + 0,28302 × (30 − 25) ≈ 26,4 → 26. Контрольное значение: 21 → 26
**Ожидалось:** Размеры изображения сохраняются, значения остаются в пределах 0–255; локальный контраст корректируется.
**Результат:** Контрольное значение: 21 → 26. Диапазон яркости: 7–240 → 10–241. Среднее: 25,943 → 31,480.
**Примечание:** CLAHE ограничивает локальное усиление гистограммы. Изменение глобального стандартного отклонения не является обязательным для локального преобразования.
