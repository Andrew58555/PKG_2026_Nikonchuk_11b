# Ответ для защиты лабораторной работы № 3, вариант 11

В лабораторной работе я разработал веб-приложение для обработки цифровых изображений. Вариант 11 включает два локальных метода пороговой обработки, адаптивную пороговую обработку и линейное контрастирование.

При загрузке изображение декодируется браузером и переводится в массив яркостей по формуле `Y = 0,299R + 0,587G + 0,114B`. Дальше алгоритмы работают с типизированным массивом, а не с отдельными вызовами GetPixel/SetPixel.

Первый метод — локальный порог по среднему. Для каждого пикселя вычисляется средняя яркость окна 21 на 21, и пиксель сравнивается с этим средним. Второй метод — Niblack. Он вычисляет порог как локальное среднее плюс коэффициент, умноженный на стандартное отклонение. В моих тестах использовалось `k = -0,20`. Адаптивный метод Sauvola дополнительно учитывает отношение локального отклонения к параметру R. В результатах отчёта использованы окно 21 на 21, `k = 0,05` и `R = 128`.

Для локальной статистики я использовал интегральное изображение и интегральное изображение квадратов. Благодаря этому сумму и сумму квадратов внутри окна можно получить за постоянное число операций. На границах изображения доступны два способа: Reflect — зеркальное отражение, и Clamp — повторение крайнего пикселя.

Отдельно реализовано линейное контрастирование. Например, у тестового изображения с низким контрастом исходный диапазон яркости был от 112 до 143, а стандартное отклонение — 7,77. После линейного контрастирования диапазон стал от 0 до 255, а стандартное отклонение выросло до 70,56. На изображении стали лучше различимы круг и прямоугольник.

Для сравнения локальных методов я использовал изображение документа с тенью. На нём локальное среднее отнесло к чёрному классу 67,20 процента пикселей, Niblack — 50,68 процента, а Sauvola — 6,50 процента. По изображению видно, что Sauvola лучше сохранил светлую поверхность листа и оставил тёмными в основном надписи и контур. На градиентном изображении доля чёрного класса после Sauvola составила 0,39 процента, в то время как локальное среднее дало 62,79 процента. Это показывает, почему адаптивный порог полезен при плавном изменении фона.

Гистограммы позволяют увидеть разницу: после линейного контрастирования распределение яркости занимает более широкий диапазон, а после бинарной обработки основная масса пикселей находится возле 0 и 255.

Обработка вынесена в Web Worker. Для больших изображений локальные методы могут обрабатываться параллельно по горизонтальным полосам. Для каждой полосы передаётся дополнительная область вокруг неё, чтобы расчёт окна на стыках совпадал с обработкой целого изображения.

В результате я реализовал методы своего варианта, проверил их на восьми тестовых изображениях, сравнил численные характеристики и гистограммы. Эксперименты показали, что выбор метода зависит от изображения: линейное контрастирование подходит для узкого диапазона яркости, а Sauvola оказался наиболее удачным на подготовленных тестах с тенью и градиентом. Для шумных и текстурных изображений параметры необходимо подбирать отдельно.
