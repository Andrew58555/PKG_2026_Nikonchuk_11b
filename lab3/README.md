## Что реализовано

Вариант 11 сочетает **локальную пороговую обработку (2 метода на выбор) + адаптивную пороговую обработку** и колонку **«реализация поэлементных операций + линейное контрастирование»**.

Основные режимы:

- линейное контрастирование по массиву интенсивностей;
- локальный порог по среднему;
- локальный порог Niblack;
- адаптивный порог Sauvola;
- дополнительный глобальный порог Оцу;
- продвинутый режим CLAHE.

Для локальных методов реализовано **интегральное изображение (SAT)** и отдельное интегральное изображение квадратов для быстрой оценки дисперсии. На один пиксель локальная статистика получается за O(1) после построения SAT.

Для краёв доступны две стратегии: `Reflect` и `Clamp`.

Обработка выполняется в **Web Worker**; для больших изображений локальные методы дополнительно распределяются по нескольким Worker-потокам по горизонтальным полосам с гало радиуса окна. Алгоритмы работают с `Uint8ClampedArray` и вложенными циклами. Canvas используется только для декодирования исходного файла в RGBA и показа результата.
