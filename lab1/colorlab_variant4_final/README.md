# ЛР1 — вариант 4: RGB ↔ HSV ↔ LAB

Готовое статическое веб-приложение на **HTML + CSS + чистом JavaScript**. Внешние библиотеки цветовой конвертации и фреймворки не используются.

## Быстрый запуск через Python

Из корня проекта:

```bash
python -m http.server 8000
```

Открыть:

```text
http://localhost:8000/
```

Автотесты:

```text
http://localhost:8000/tests/
```

Node.js для этого способа **не нужен**. Python только раздает статические файлы; все расчеты выполняются JavaScript-кодом в браузере.

## Что реализовано

- вариант 4: **RGB ↔ HSV ↔ LAB**;
- три модели видны одновременно;
- точные числовые поля для всех компонентов;
- 9 ползунков;
- палитра в каждой панели;
- автоматический пересчет остальных моделей;
- динамические градиенты ползунков;
- D65 / D50 / E;
- динамический расчет RGB↔XYZ-матриц из xy-координат первичных цветов и точки белого;
- ручная математика 3×3-матриц, включая `inverse3()`;
- Clipping / Scaling;
- предупреждение при выходе LAB за gamut sRGB;
- Model / View / Controller;
- 28 автоматических микро-тестов прямо в браузере.

Требование UCR/GCR относится к расчету CMYK. В варианте 4 CMYK отсутствует, поэтому этот алгоритм не применяется.

## Архитектура

- **Model** — математика; не обращается к DOM.
- **View** — HTML/DOM, поля, палитры, слайдеры и вывод результата.
- **Controller** — получает события View, вызывает Model и синхронизирует все представления.

Основные маршруты:

```text
RGB ↔ HSV
RGB ↔ XYZ ↔ LAB
```

XYZ — внутреннее промежуточное пространство, а не четвертая редактируемая модель.

## Динамическая RGB↔XYZ-матрица

В рабочем коде нет готовых матриц D65/D50/E. Хранятся xy-координаты sRGB primaries и выбранного источника:

```text
xy primaries -> P
xy white -> W
S = P^-1 * W
M = P * diag(S)
M^-1 = собственный inverse3(M)
```

При смене D65/D50/E `ColorConverter.setIlluminant()` создает новый контекст и пересчитывает матрицы.

## Gamut mapping

При LAB→RGB возможен выход линейных RGB за `[0;1]`.

- **Clipping** — каждый канал ограничивается независимо.
- **Scaling** — весь диапазон каналов совместно сжимается в `[0;1]`.

Интерфейс сообщает о таком случае и показывает линейный RGB до коррекции.
