# Краткая защита — ЛР1, вариант 4

## Запуск

Локально:

```bash
python -m http.server 8000
```

Приложение: `http://localhost:8000/`

Тесты: `http://localhost:8000/tests/`

Для преподавателя проект лучше опубликовать через GitHub Pages. Тогда приложение и тесты открываются по публичной ссылке без установки Python/Node.js.

## Вступление

«У меня вариант 4 — RGB ↔ HSV ↔ LAB. Проект написан на чистом HTML, CSS и JavaScript, без библиотек цветовой конвертации. Код разделен на Model, View и Controller. RGB↔HSV реализован напрямую, RGB↔LAB — через промежуточный XYZ. Матрица RGB↔XYZ не зашита: она рассчитывается на лету для D65, D50 или E. Есть Clipping/Scaling, динамические градиенты и 28 автоматических браузерных тестов.»

## Что показать

1. `RGB(255,0,0)` → `HSV(0,100,100)` и LAB около `(53.24, 80.09, 67.20)` при D65.
2. Подвигать RGB/HSV/LAB — остальные модели пересчитываются автоматически.
3. Показать, что градиенты ползунков меняются вместе с текущим цветом.
4. Переключить `D65 → D50 → E` — меняются точка белого, XYZ, LAB и RGB→XYZ-матрица.
5. Ввести `LAB(50,127,127)` — появляется предупреждение о выходе за gamut.
6. Переключить `Clipping ↔ Scaling` — результат RGB различается.
7. Показать `src/model`, `src/view`, `src/controller`.
8. Открыть `/tests/` — должно быть `28 / 28`, ошибок `0`.

## Файлы

- `matrix.js` — матрицы 3×3: умножение, определитель, обращение.
- `illuminants.js` — D65/D50/E и динамическое построение RGB↔XYZ.
- `hsv.js` — RGB↔HSV вручную.
- `rgbXyz.js` — gamma, RGB↔XYZ, Clipping/Scaling.
- `lab.js` — XYZ↔LAB.

- `appView.js` — DOM и элементы интерфейса.
- `gradientSlider.js` — динамические треки ползунков.
- `colorController.js` — связь View и Model.

## Ключевые ответы

**Почему есть XYZ?** Это внутреннее промежуточное пространство для RGB↔LAB; пользователь редактирует только RGB, HSV и LAB.

**Почему матрица не жесткая?** Хранятся xy primaries sRGB и xy выбранного illuminant. Строится `P`, затем `S=P^-1W`, `M=P·diag(S)`, а обратная матрица считается собственной `inverse3()`.

**Зачем gamma?** Матрица RGB↔XYZ применяется к линейным RGB, а обычные значения sRGB gamma-кодированы.

**Почему LAB меняется при D65/D50/E?** CIELAB считается относительно reference white.

**Clipping vs Scaling?** Clipping независимо обрезает каналы; Scaling совместно сжимает их диапазон в `[0;1]`.

**Где Python?** Python не является частью приложения. `python -m http.server` только локально раздает статические файлы. На GitHub Pages Python вообще не используется.

**Почему нет UCR/GCR?** Это требование относится только к вычислению CMYK. В варианте 4 CMYK нет.
