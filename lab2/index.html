Что реализовано

Без сторонних парсеровМетаданные извлекаются из сигнатур, заголовков, чанков и TIFF IFD вручную.
Потоковая обработкаДля каждого файла читаются только необходимые диапазоны Blob, без загрузки изображения целиком.
Web WorkersНесколько worker-потоков обрабатывают файлы параллельно, UI остаётся отзывчивым.
ВалидацияПроверяются magic numbers, границы структур, PNG IEND, JPEG EOI и ключевые TIFF-смещения.
